# Parrot Quiz Game

## Repository
https://github.com/ut4hr4ptor/hayesCarrascoSparky_FinalProject

## Description
This project will emulate a quiz-style game where the player is shown a photo of a parrot and must answer the correct species name.

## Features
- Visual images
  - The program will showcase a picture of a different parrot species per question.
- Varying answers
  - Three different answer buttons will appear per each question, with two being incorrect. This layout is inspired by Kahoot and Quizlet.
- Correct answer score
  - The program will store the total amount of correct answers per each completed question. This allows the player to create a memory of what species name matches each parrot image, creating a learning experience.
 
## Challenges
- Figuring out how to display a screen that functions as a three-button option choice with an image.
- Making sure incorrect answers do not count towards the total correct answer score.
- Deciding whether or not the game's questions will be randomized or stay consistent.

## Outcomes
Ideal Outcome:
- The ideal outcome is for the program to be a functional and educational quiz game with a total correct answer score that encourages the user to repeat the game with randomized questions. 

Minimal Viable Outcome
- The bare essential would be for a playable game that shows players a question and requires the player to press the correct answer button.
