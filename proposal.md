# Top-down 2D RPG

## Repository
https://github.com/ut4hr4ptor/hayesCarrascoSparky_FinalProject

## Description
This project will emulate a top-down game centered around making choices in a 2D role-play style environment.
The game allows creative liberty when it comes to the player's character and their life.

## Features
- Visual character customization
  - The program will allow for the player to input text to name their character, choose from different character types, personality traits, and more; storing this info and implementing it into how the game functions/reacts. This will be displayed visually.
- Choice-based gameplay
  - Multiple outcomes/outputs will come from stored memory regarding the player's choices and behavior during the game's base events.
- Sprite artwork and backgrounds
  - Artwork designed for the game's different locations, character customization, animations, and more.
 
## Challenges
- Being able to store so much data/user inputs while not cluttering the code.
- Making sure all choices and their effects are accounted for and not mixed up.
- Figuring out how to build the world and the story itself. Worldbuilding takes a lot of thought.
- Cramming in multiple different 2D environment art, different character sprites, dialogue animations, and more.

## Outcomes
Ideal Outcome:
- The ideal outcome is for the program to be functional and entertaining with multiple endings that encourage the user to repeat the game. 

Minimal Viable Outcome
- The bare essential would be for a playable game that focuses on creative customization with a goal of at least two different endings, 3 different character choices, and several interactions between the player and the game's NPCs.
